# Технологии тестирования программных продуктов

Работы 1.0-3 посвящены ручному тестированию и оформлены в отчётах. Модульные тесты на pytest находятся в каталогах с lab-04 по lab-06. Каталог lab-07 содержит интеграционные тесты API велопроката, а lab-08 содержит браузерные тесты списка задач.

Для запуска откройте каталог нужной работы. В работах 4-6 установите pytest. В работах 7 и 8 установите зависимости командой `python -m pip install -r requirements.txt`. Для работы 8 установите Chromium командой `python -m playwright install chromium`. Запуск тестов из каталога работы: `python -m pytest -q`.
